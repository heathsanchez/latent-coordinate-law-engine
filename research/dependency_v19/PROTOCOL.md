# V19 dependency-closed certificate boundary
Based on V18 authentic-history controls. A function's AST can remain unchanged when a referenced global changes, invalidating the result. Freeze conservative candidate classification: unchanged transitive module definitions, changed dependency -> WITHHOLD, unknown external binding -> UNKNOWN. Run a deliberately adversarial injected global mutation independent of real upstream commits; keep real V18 as regression. This is a bounded syntactic prototype, not actual full Python semantic equivalence: reflection, indirect globals, imports, environment, aliases, dynamic dispatch and transitive external changes require separate authority and checker. Equal-information conventional dependency hashing can implement exactly the same check; no comparative advantage claimed.
